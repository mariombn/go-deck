# go-deck v0.3

O Rise Mode Vision 2 ganha suporte USB no Windows e no macOS. O Go Deck lê as 15 teclas, atualiza os LCDs, troca de página pelo aparelho e reconecta após a desconexão do USB. A versão para macOS passa a ser distribuída em DMG.

## Rise Mode Vision 2

- Feche o OpenDeck, o software da Rise Mode e outros controladores antes de abrir o Go Deck.
- Conecte o Vision 2 e confira o estado **Conectado** no painel **Rise Mode Vision 2**. Use **Controlar USB** para liberar ou retomar o acesso ao aparelho.
- Salve a configuração para enviar os rótulos, cores, emojis e imagens às teclas. O hardware mostra as primeiras 3 linhas × 5 colunas da página ativa.
- No macOS, ações de teclado e mouse precisam de permissão de **Acessibilidade**. Se o sistema pedir para permitir a conexão do acessório USB, autorize o Vision 2.

Os builds e testes automatizados passaram em Windows, macOS e Linux. A confirmação das teclas, dos LCDs e da reconexão com um Vision 2 físico no Windows e no macOS segue pendente. Veja o [guia de conexão e testes](https://github.com/mariombn/go-deck/blob/v0.3/docs/vision2.md).

## Downloads

- **Windows:** `go-deck.exe`.
- **macOS:** abra `go-deck-macos.dmg` e arraste `go-deck.app` para Aplicativos.
- **Linux x86_64:** `go-deck_0.3.0_linux_amd64.AppImage`, `.deb` ou `.rpm`.
- Use `SHA256SUMS` para conferir a integridade dos downloads.

O nome da release e da tag é `v0.3`. Os instaladores usam a versão `0.3.0`.
